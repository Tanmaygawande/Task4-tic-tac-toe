# Task 4 – Tic-Tac-Toe AI

A console Tic-Tac-Toe game where the user plays against an AI.

The AI uses the **Minimax algorithm**, so it checks possible future moves before choosing its move.

### Run

```bash
python tic_tac_toe.py
```

- You are `X`
- The computer is `O`
- Enter positions from 1 to 9
